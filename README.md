# HEXA CROWN · 왕관을 향한 진군

제공된 HEXA COMMAND 프로토타입을 바탕으로 만든 중세 턴제 영토 전쟁 보드게임입니다. 37칸 육각 지도, 카탄식 주사위 생산, 이동·점령, 병종 상성과 승리 점수를 유지하고 화면과 삽화를 새로 제작했습니다.

## 파일을 바로 열어 플레이

압축파일 맨 위의 **`HEXA-CROWN.html`**을 Chrome·Edge·Firefox·Safari 같은 브라우저로 열면 설치 없이 플레이할 수 있습니다. AI 대전과 한 기기의 2인 교대 대전을 지원합니다. 브라우저에서 저장을 차단하면 게임은 실행되지만, 창을 닫으면 진행 상황이 사라집니다.

GitHub에서 받는 경우 게임 브랜치의 **Code → Download ZIP**을 선택하고 압축을 풀어 주세요. 저장소의 HTML 코드 화면 대신 내려받은 `HEXA-CROWN.html`을 브라우저로 엽니다.

프로젝트 안에서는 `public/play.html`이 같은 실행 파일입니다. `public/index.html`은 서버용 진입점이므로 파일을 직접 열 때는 표시된 **설치 없이 게임 열기** 링크를 선택하세요.

소스를 수정한 뒤에는 `npm run build`로 루트의 `HEXA-CROWN.html`, `public/play.html`, `dist/HEXA-CROWN.html`을 다시 생성할 수 있습니다. 이 빌드에는 추가 패키지가 필요하지 않습니다.

## 온라인 대전 서버 실행

Node.js 22 이상에서 저장소 루트(`/workspace/-`)를 작업 디렉터리로 사용합니다.

```sh
npm ci
npm start
```

기본 포트는 `3000`이며 `PORT` 환경 변수로 변경할 수 있습니다. 개발 중에는 `npm run dev`로 서버 변경을 감지합니다. 별도 빌드나 API 키는 필요하지 않습니다.

## 플레이

- **AI 대전:** 푸른 사자 군단을 선택하고 이동 가능한 영토를 클릭합니다. 각 부대는 턴마다 한 번 이동하고 한 번 공격할 수 있습니다. 공격하면 해당 턴의 이동을 마칩니다.
- **2인 교대:** 상단 대전 모드 또는 하단 '새로운 원정 시작'에서 선택합니다. 한 기기로 번갈아 플레이합니다.
- **온라인:** 상단 '멀티플레이'에서 방을 만들고 초대 링크나 6자리 코드를 공유합니다. 두 명 모두 접속하면 시작하며 서버가 턴과 명령을 검증합니다.
- **승리:** 10 VP 달성 또는 적 본성 점령. 영토 3칸마다 +1, 광산 +1, 전초기지 +1, 본성 +2 VP입니다.
- **자원:** 턴 시작에 주사위를 자동으로 굴립니다. 일치하는 숫자의 점령지에서 양쪽 플레이어가 자원을 얻으며 본성·전초기지는 2배 생산합니다. 최초 점령도 자원 1을 제공합니다.
- **교역·재보급·건설:** 교역소에서 자원 3을 황금 1로 바꾸고, 부대 재보급은 식량 1로 체력 4를 회복합니다. 전초기지는 목재 2, 철광 1, 황금 1입니다.

AI·교대 대전은 브라우저 `localStorage`에 자동 저장됩니다. 온라인 좌석 토큰은 탭별 `sessionStorage`에 보관하므로 새로고침 후 같은 탭에서 복귀할 수 있습니다. 한쪽이 연결을 잃으면 전투를 정지하고 재접속을 기다립니다.

온라인 방은 **메모리 기반 프로토타입**입니다. 서버를 재시작하면 방이 초기화됩니다. 두 사람은 같은 서버 주소에 접속해야 하며, 인터넷 대전을 제공하려면 이 Node 서버를 WebSocket을 지원하는 HTTPS 호스트에 배포해야 합니다. 계정·매칭·영구 저장·관전 기능은 포함하지 않습니다.

## 검증

```sh
npm test
npm run test:browser
npm run test:standalone
```

규칙 및 서버 테스트는 Node 내장 테스트 러너로 실행합니다. 브라우저 테스트는 기본적으로 `/usr/bin/chromium`을 사용하며 다른 설치 경로는 `CHROMIUM_PATH`로 지정합니다. 테스트는 자체 임시 서버를 시작하고 종료합니다.

- 이동 경로, 지형·병종 상성, 반격, 점령, 모집 비용, 생산, 교역, 회복, 승리, AI 한 게임
- 온라인 방 생성·참가, 차례 검증, 상태 동기화, 잘못된 접속 토큰 거부, 재접속
- 실제 브라우저 조작, 자동 저장 복원, 390/768/1024px 반응형, 두 브라우저의 온라인 대전
- 단일 HTML의 네트워크 차단·저장소 차단 상태 실행, AI 턴, 로컬 2인 대전

화면 캡처는 무시된 `test-results/`에 저장됩니다.

## 구조와 아트

| 파일                | 역할                                                                    |
| ------------------- | ----------------------------------------------------------------------- |
| `public/engine.js`  | UI와 독립적인 게임 규칙; 클라이언트와 서버가 공유                       |
| `public/art.js`     | 직접 제작한 SVG 군단 말, 기병·말 갑옷, 문장, 성채, 지형, 자원·UI 아이콘 |
| `public/app.js`     | 지도와 인터페이스, AI, 자동 저장, 소리, 온라인 연결                     |
| `public/styles.css` | 양피지·청록색 디자인과 반응형 레이아웃                                  |
| `server.js`         | 정적 파일, 서버 검증 WebSocket 대전, 재접속 좌석 관리                   |

이모지, 외부 이미지, 이미지 CDN, 외부 폰트 요청을 사용하지 않습니다. 모든 그림은 이 프로젝트에서 직접 작성한 SVG이며 시스템 한글 폰트를 사용합니다. 효과음은 Web Audio로 합성합니다. 화면 이동과 애니메이션은 `prefers-reduced-motion` 설정을 따릅니다.
